##  Объекты в VPS
- суперблок
- файловый индекс
- элемент каталога
- открытый файл, который связан с процессом
В каждом объекте содержится операции (действия), которые можно выполнить над данным объектом

```
super_operations
inode_operations
dentrey_operations
file_operations
```

## Операции суперблока
```C++
struct struct_operations {
	void(*dentrey_index)(struct inode*);
	int (*write_super)(struct superblock*);
}


struct super_block* sb;
sb->s.op->write_super(sb);
```

## Последовательность шагов функции open
1) Ядро выполняет поиск в таблице дескрипторных файлов процесса первую незадействованную позиицию. Номер (индекс) этой позиции является возвращенным значением функции open
2) Ядро  выполняет поиск не занятой позиции. В таблице открытых файлов ядра.
   Если не занятая позиция найдена, то в найденную запись таблица открытых файлов процесса наосится ссылка на найденную запись таблицы ядра
   В  таблице открытых файлов в ядре в надейнно
