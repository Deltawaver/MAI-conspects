Пример:
Линейное преобразование вида \nu = (\xi - a)/(b-a), \xi~R(a, b). Т.е. \nu~R(0, 1)
Есть дав пути решения.

Путь 1.
$\nu = \fi(\xi)$, \fi(.) - дописать, что это
$f_\n (y) =|d/dy \fi^(-1)*(y)|f_\xi[\fi^(-1)(y)]$
nu = (\xi - a)/(b-a) // fi(x) = y = (x-a)/(b-a)
fi^(-1)(y) = x = y(a+b) + a
d/dyfi^(-1)(y) = b - a
f_\xi(a) = {1/(b-a), x принадлежит [a, b]; 0, иначе}
f_n(y) = {(b-a) * 1/(b-a), y(b-a) + a принадлежит [a, b]; |d/dy fi^(-1)(y), f_\xi[fi^(-1)(y)]|; 0, иначе}

= {1, a <= y(b-a)+a<=b, 0<=y<= 1; 0, иначе}

Путь 2
Т.к. \xi~R(a, b), то по определению P(\xi <= x) = F_\xi(x) = {(x-a)/(b-a), a <= <b; 0, x < a; 1, x >= b}
Далее так как nu = (\xi - a)/(b-a) (т.е. y = (x-a)/(b-a)), то x = y(b-a), a
Тогда
P(nu <= y) = {0, y(b - a) + a <= a; (y(b-a) + a - a)/(b-a), a <= y(b-a)+a<=0; 1, y(b-a)+a >= b} = {0, y <= 0; y, 0 <= y <= 1; 1 y >= 1} => n~R(0, 1)
